# 🌿 AI Powered Medicinal Plant Detection using Deep Learning

An AI-powered web application that detects and identifies medicinal plants using Deep Learning and Computer Vision techniques.  
Users can upload a plant leaf image, and the system predicts the medicinal plant along with useful information such as medicinal uses, scientific name, and confidence score.

---

## 🚀 Features

- 🌱 Medicinal plant detection from leaf images
- 🤖 Deep Learning based image classification
- 📷 Upload plant images through web interface
- 📊 Prediction confidence score
- 🧠 Trained CNN/TensorFlow model
- 💻 User-friendly interface using Streamlit/Flask
- 📚 Displays plant details and medicinal uses

---

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Pandas
- Streamlit / Flask
- Matplotlib
